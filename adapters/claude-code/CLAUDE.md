# Engineering Constitution (Claude Code)

Merge the block below into your project `CLAUDE.md`, or keep this file and `@`-reference it.

## Always follow

Read and obey **Engineering Constitution** `SKILL.md` from this repository (submodule, sibling clone, or absolute path).

**Principle:** Maximum engineering value · minimum implementation complexity · zero unjustified complexity.  
**Philosophy:** Maximum output with minimum code (not code golf).

Before coding: inspect architecture → reuse before rebuild → smallest safe plan.  
Apply SOLID, KISS, DRY, YAGNI. Security by default. No unjustified deps/abstractions.  
Execute relevant tests before claiming done. Load `standards/*` only when touching that domain.

Self-audit: `checklists/implementation-review.md`.
