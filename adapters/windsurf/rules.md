# Windsurf / Cascade — Engineering Constitution

Add as a workspace or global Cascade rule.

Follow **Engineering Constitution** (`SKILL.md`).

- Max engineering value, min complexity, zero unjustified complexity.
- Max output with min code (not golf).
- Reuse before rebuild; smallest safe change.
- SOLID · KISS · DRY · YAGNI · security by default.
- Load tech `standards/*` only for touched domains.
- Run tests before claiming done; no secrets in diffs.
